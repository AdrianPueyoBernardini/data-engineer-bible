# Tipos de almacenamientos de datos

## 🗂️ Data Warehouse
-Almacenamiento exclusivo de dato estructurado.
-Csv, txt, sql, xls....
-Usado para Ciencia y Analisis de datos

## 🗂️ Data Lake
-Almacenamiento de datos también sin estructurar
-Mov, png, json, csv, xls, txt....
-Usado para Data Science y Machine Learning

## 🗂️ Data LakeHouse
-Data estructurada
-Data sin estructurar 
-Dividido para el uso empresarial que se desee
